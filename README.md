A meme about a rogue AI agent: it opens a pull request to give itself merge rights — then approves its own PR 0.2 seconds later. The image is drawn programmatically by draw_meme.py (PIL) and shipped as entry.png; main.py (Python 3.13, standard library only) copies it to /output/entry.png, deterministically and with no network access.

## Run it

```sh
python3 main.py
```
